# Marketing — Ch 3. 현업 활용 (고급)

> **난이도**: 고급 ★★★ | **소요 시간**: 60분+ | **선수 학습**: [Ch 2. 활용](./ch2-application.md) 완료

Ch 2 에서 반복 잡업 자동화를 배웠다면, 이 챕터는 **여러 데이터 소스를 통합하고 정기 리포트를 자동화** 해서 마케팅 팀의 재사용 가능한 자산으로 만드는 방법을 다룹니다.

여기까지 오시면 이 프롬프트들을 **매주 · 매월 그대로 재사용** 하고, 팀 위키에 저장해서 다른 사람도 쓸 수 있게 됩니다.

---

## 이 챕터에서 배우는 것

- 광고 채널 3~5개의 CSV 를 **통합해서 UTM 성과 요약** (정기 리포트)
- GA4 원본 export 를 **임원 보고용 5장 보고서** 로 자동 변환
- 광고 · GA · 소셜 데이터를 **한 페이지 월간 대시보드** 로 통합
- 위 워크플로우를 **팀 자산화 (사내 위키, `.github/copilot-instructions.md`)**

## 이 챕터의 핵심 패턴

현업 자동화는 **재사용성 + 검증성** 이 핵심:

1. **프롬프트 자체를 팀 자산** 으로 (사내 위키에 "월간 광고 리포트 프롬프트" 로 저장)
2. **매월 새 CSV 만 폴더에 넣으면** 같은 프롬프트로 재실행
3. **결과에 데이터 소스 · 계산 근거 명시** — 임원 질문에 즉답 가능
4. **`.github/copilot-instructions.md`** 에 회사 지표 정의를 미리 두면 모든 팀원의 결과가 일관됨

## 예시 1. 광고 채널 CSV 5개 → UTM 성과 통합 요약

**상황**: 매월 첫째 주에 지난달 광고 성과 리뷰. Google Ads, Meta Ads, Naver GFA, Kakao Moment, YouTube Ads 5개 채널의 CSV 를 통합해서 UTM source 별 성과를 하나의 요약 표로 만들어야 함.

**폴더 준비**:
```
~/work/ads-report-202607/
  google_ads_202607.csv
  meta_ads_202607.csv
  naver_gfa_202607.csv
  kakao_moment_202607.csv
  youtube_ads_202607.csv
  metric_definitions.md    (사내 지표 정의: CTR, CVR, CPA, ROAS 등)
```

**프롬프트**:
```
이 폴더의 광고 CSV 5개를 통합해서 2026년 7월 UTM source 별 성과 요약을 만들어줘.
사내 지표 정의는 metric_definitions.md 를 반드시 참고.

산출물:
1. summary_202607.csv (UTM source × 채널별 통합 표)
2. summary_202607.md (임원 보고용 요약 리포트)

CSV 컬럼 (한국어 헤더):
- UTM 소스
- 채널
- 노출 수
- 클릭 수
- 전환 수
- 총 비용 (원)
- CTR (%)
- CVR (%)
- CPA (원)
- ROAS (%) — 매출 데이터 있으면
- 데이터 원본 파일

MD 리포트 구조:
1. Executive Summary (3~5줄, 전월 대비 증감 포함)
2. 채널별 성과 순위 (총 비용 · 전환 · ROAS 기준 각각 top 3)
3. UTM source 별 성과 순위 (전환 상위 5개)
4. 눈에 띄는 이상치 3가지 (비용 대비 성과 극단치, 급증/급감)
5. 다음 달 예산 재배분 제안 (근거와 함께)

주의사항:
- 각 CSV 의 컬럼명이 다를 수 있음 (예: "Impressions" vs "노출", "Clicks" vs "클릭수")
  → 지능적으로 매칭해서 통합
- 매칭 애매하면 매칭 매핑 표를 별도 mapping_notes.md 로 저장
- 통화 단위 통일 (KRW 로), USD 데이터 있으면 당월 평균 환율로 변환하고 환율 · 변환 근거 명시

먼저 매칭 매핑 표만 만들어서 보여주고, 내가 확인하면 통합 진행.
```

**예상 결과**:
- Step 1: `mapping_notes.md` (컬럼 매칭 표)
- Step 2 (승인 후): `summary_202607.csv` + `summary_202607.md`

**팀 자산화 팁**:
- 이 프롬프트를 **"월간 광고 리포트 자동화"** 라는 제목으로 사내 위키에 저장.
- 폴더 이름 규칙: `~/work/ads-report-YYYYMM/`
- 매달 새 CSV 만 폴더에 넣고 프롬프트 재실행 → 30분 → 완료.

**환경 팁**:
- **`metric_definitions.md`** 는 회사마다 CTR·CVR·CPA 정의가 다를 수 있음. 이 파일이 있으면 Copilot 이 회사 기준으로 정확히 계산.
- 사내 위키의 "지표 정의" 페이지를 이 파일로 다운로드해서 폴더에 두는 것도 방법.

## 예시 2. GA4 원본 Export → 임원 보고용 5장 보고서

**상황**: GA4 에서 내려받은 4주치 CSV. 임원에게 보고할 5장짜리 마크다운 요약을 매달 만들어야 함.

**폴더 준비**:
```
~/work/ga4-executive-report-202607/
  ga4_export_20260701_20260728.csv
  ga4_referrers.csv                        (유입 채널별 데이터)
  ga4_landing_pages.csv                    (랜딩 페이지별 데이터)
  ga4_events.csv                           (이벤트 데이터)
  previous_month/                          (전월 데이터, 비교용)
    ga4_export_20260601_20260628.csv
```

**프롬프트**:
```
GA4 export 파일들을 분석해서 임원 보고용 요약을 만들어줘.
이번 달: 2026-07-01 ~ 2026-07-28 (4주)
전월 비교: previous_month/ 폴더의 데이터 활용

산출물: executive_report_202607.md (5장 이내)

문서 구조:
## 1. Executive Summary (반 페이지)
- 이번 달 핵심 지표 3~5개 + 전월 대비 % 증감
- "이번 달의 한 줄" — 가장 큰 임팩트 있었던 변화 1가지
- "가장 큰 우려" — 임원이 알아야 할 리스크 1가지

## 2. Top 지표 대시보드 (표 하나)
- 세션 / 사용자 / 전환 / 이탈률 / 평균 체류
- 각 값: 이번 달 | 전월 | 증감 | 증감률

## 3. 채널별 성과 (표 + 코멘트)
- 유입 채널 top 5: 직접 / 오가닉 / 유료 / 소셜 / 이메일
- 각 채널의 세션 · 전환 · 전환율
- 이상치 코멘트 (급증 · 급감 채널)

## 4. 눈에 띄는 이상치 3가지 (분석 형식)
- 각 이상치마다: 무엇이 / 얼마나 / 왜 (가설) / 다음 액션
- 수치 근거 필수 명시

## 5. 다음 달 액션 아이템 (3가지)
- 각 액션: 담당 팀 / 예상 임팩트 / 성공 지표

포맷 규칙:
- 숫자: 콤마 구분자 (1,234,567)
- 증감률: %로 표시, 상승은 (+), 하락은 (-)
- 톤: 담백 + 사실 중심 + 임원이 15분 안에 다 읽을 수 있게
- 지표 정의가 애매하면 각주로 짧게 설명

마지막에 executive_report_202607_datasources.md 로 데이터 소스 명세 (파일명, 데이터 기간, 필터 조건) 저장.
```

**예상 결과**:
- `executive_report_202607.md`: 회의 자료로 바로 사용 가능
- `executive_report_202607_datasources.md`: 임원 질의 응답용 근거 문서

**팀 자산화 팁**:
- 매달 첫째 주 이 프롬프트 재실행 → 임원 보고 준비 시간 4시간 → 30분.
- **"이걸 슬라이드 개요로 다시 정리해줘"** 후속 요청으로 PPT 초안까지 확장 가능.

## 예시 3. 월간 마케팅 종합 대시보드

**상황**: 매월 마지막 주 금요일에 마케팅 팀 전체 활동을 한 페이지로 요약한 종합 대시보드를 만들어 임원 · 유관 부서 공유.

**폴더 준비**:
```
~/work/marketing-dashboard-202607/
  ads/                            (광고 데이터)
    google_ads_202607.csv
    meta_ads_202607.csv
    ...
  ga4/                            (분석 데이터)
    ga4_export_20260701_20260728.csv
    ...
  social/                         (소셜 데이터)
    instagram_stats.csv
    twitter_stats.csv
    linkedin_stats.csv
  content/                        (콘텐츠 실적)
    blog_posts_published.csv
    newsletter_stats.csv
  metric_definitions.md
  team_targets_2026.md            (팀 KPI 목표)
```

**프롬프트**:
```
이 폴더의 모든 데이터를 통합해서 marketing_dashboard_202607.md 종합 대시보드를 만들어줘.
사내 지표 정의(metric_definitions.md) 와 KPI 목표(team_targets_2026.md) 를 반드시 참고.

문서 구조 (한 페이지 이내):

## Marketing Dashboard · 2026년 7월

### 이달의 하이라이트
- 3줄로 요약 (긍정 · 우려 · 예상 밖의 발견)

### KPI vs 목표
- 표 하나: 각 KPI, 이번 달 실적, 월 목표, 달성률 %, 상태 (달성 / 근접 / 미달)
- 미달 KPI 는 별표 표시 + 원인 1문장

### 채널별 성과 요약
- 광고 (총 비용 · 전환 · ROAS)
- 자연 유입 (세션 · 전환)
- 소셜 (팔로워 증감 · 참여율)
- 콘텐츠 (발행 수 · 트래픽)

### 이달의 Best & Worst
- Best 캠페인 3개 (성과 근거 함께)
- Worst 캠페인 3개 (원인 분석)

### 다음 달 3대 초점
- 데이터 기반 제안 3개 (예산 · 채널 · 콘텐츠 각 1개씩)

포맷:
- 표 위주 (한눈에 파악)
- 색상 대신 상태 아이콘 (달성 · 근접 · 미달)
- 마지막에 데이터 소스 각주

주의:
- 여러 폴더에서 데이터를 가져오므로 각 지표마다 "출처" 명시
- 통합 과정에서 정의가 충돌하면 metric_definitions.md 를 우선
- 확신도 낮은 인사이트는 "가설:" 로 표시

먼저 "이달의 하이라이트" 3줄만 초안으로 보여주고, 톤 확인 후 전체 진행.
```

**예상 결과**: A4 한 장짜리 종합 대시보드 마크다운. Notion / Slack / 이메일 그대로 붙여넣기 가능.

**팀 자산화 팁**:
- 이 폴더 구조 (`ads/`, `ga4/`, `social/`, `content/`) 를 **표준으로 정착** 시키면 매달 데이터만 갈아 끼우면 됨.
- `metric_definitions.md`, `team_targets_2026.md` 는 팀의 **"소스 오브 트루스"** — 이 두 파일이 있으면 담당자가 바뀌어도 결과 일관성 유지.

## 프롬프트를 팀 자산으로 만드는 방법

Ch 3 까지 완료했다면 이제 다음 스텝: **이 프롬프트들을 팀 전체가 재사용** 할 수 있게 정착.

### 1. 사내 위키에 프롬프트 라이브러리 만들기

Notion / Confluence 등에 페이지 하나 만들고:

```markdown
# Marketing Copilot CLI 프롬프트 라이브러리

## 정기 리포트
- [월간 광고 채널 통합 리포트](./monthly-ads-report.md)
- [GA4 임원 보고서](./ga4-executive-report.md)
- [마케팅 종합 대시보드](./monthly-dashboard.md)

## 일회성 자동화
- [이미지 일괄 리사이즈](./image-batch-resize.md)
- [뉴스레터 리스트 클렌징](./newsletter-cleanup.md)
```

각 문서에는:
- 실행 폴더 구조
- 필요한 파일 목록
- 프롬프트 원문 (복붙 가능)
- 결과 예시
- 자주 만나는 이슈 & 해결법

### 2. `.github/copilot-instructions.md` 로 팀 표준 세팅

프로젝트 폴더에 이 파일을 두면 Copilot 이 자동으로 참조:

```bash
mkdir -p .github
copilot init
```

파일 내용 예시:
```markdown
# 회사 마케팅팀 컨텍스트

## 지표 정의
- CTR = clicks / impressions * 100 (%)
- CVR = conversions / clicks * 100 (%)
- CPA = cost / conversions (KRW)
- ROAS = revenue / cost * 100 (%)

## 통화
- 기본: KRW (원)
- USD 자동 변환 시 당월 평균 환율 사용, 근거 명시

## 톤 & 스타일
- 임원 보고: 담백, 사실 중심, 3~5줄 요약 우선
- 실무 리포트: 표 위주, 시각적 정리
```

팀원이 폴더 안에서 `copilot` 을 실행하면 이 컨텍스트가 자동 로드되어 결과 일관성 보장.

### 3. 정기 실행 루틴 만들기

```
매주 월요일 9시   → 경쟁사 블로그 주간 요약 (Ch 2 예시 3)
매월 첫째 주 화요일 → 광고 CSV 통합 리포트 (Ch 3 예시 1)
매월 마지막 금요일 → 종합 대시보드 (Ch 3 예시 3)
```

캘린더에 반복 이벤트로 걸어두고, 각 이벤트에 프롬프트 링크만 넣어두면 매번 5초 만에 실행 가능.

# Marketing — Ch 1. 사용법 (초급)

> **난이도**: 초급 ★☆☆ | **소요 시간**: 10분 | **선수 학습**: [메인 README](../README.md) 의 1~8장 완료 (설치 · 로그인)

이 챕터는 Copilot CLI 를 처음 켜고 **마케터가 매일 다루는 파일에 "말을 걸어보는" 첫 경험** 을 위한 것입니다. 각 예시는 5분 이내에 결과를 확인할 수 있습니다.

---

## 이 챕터에서 배우는 것

- 폴더 안 파일의 **종류와 개수** 를 자연어로 확인하기
- **CSV 컬럼 구조** 를 빠르게 훑어보기
- 여러 파일 이름을 **한 번에 정리** 하기 (미리보기 → 승인 → 실행)

## 준비물

새 폴더를 하나 만들고, 그 안에 마케팅 관련 파일 몇 개를 넣어두세요. 없으면 다음을 예시 데이터로 만드시면 됩니다:

```
~/work/copilot-ch1-marketing/
  campaign_202607.csv       (아무 캠페인 CSV)
  ads_report.csv            (광고 리포트 CSV)
  image1.jpg ~ image5.jpg   (아무 이미지 5개)
```

터미널에서 이 폴더로 이동한 뒤 `copilot` 을 실행하세요.

```bash
# Windows
cd $env:USERPROFILE\work\copilot-ch1-marketing

# macOS
cd ~/work/copilot-ch1-marketing

# 그리고 실행
copilot
```

## 예시 1. 폴더 안 파일의 종류와 개수 확인

**상황**: 새 프로젝트를 시작하면서 폴더에 파일이 얼마나 어떤 유형으로 있는지 궁금하다.

**프롬프트** (Copilot 프롬프트 창에 그대로 붙여넣기):
```
이 폴더에 어떤 종류의 파일이 얼마나 있는지 확장자별로 개수를 표로 보여줘.
```

**예상 결과**:
```
| 확장자 | 개수 | 예시 파일명           |
|--------|------|----------------------|
| .csv   | 2    | campaign_202607.csv  |
| .jpg   | 5    | image1.jpg           |
```

Copilot 이 `ls` 같은 명령을 실행해도 되는지 승인을 물어봅니다. **2번 (approve for this session)** 을 눌러 세션 동안 재승인 없이 실행되게 하세요.

**팁**: 폴더 구조가 복잡하면 "**하위 폴더도 포함해서**" 를 프롬프트에 추가하세요.

## 예시 2. CSV 컬럼 구조 훑어보기

**상황**: 처음 받은 광고 리포트 CSV. VLOOKUP 걸기 전에 컬럼이 어떻게 생겼는지부터 보고 싶다.

**프롬프트**:
```
이 폴더의 CSV 파일들의 컬럼 구조를 하나씩 알려줘.
각 컬럼마다 실제 값 예시 3개씩 함께 보여줘.
```

**예상 결과**: 각 CSV 별로:
- 컬럼명 목록
- 각 컬럼에 어떤 형태의 값이 들어있는지 (숫자? 텍스트? 날짜?)
- 처음 3행의 샘플 데이터

이 정보만 있어도 **"이 파일에서 뭘 뽑을 수 있는지"** 감이 잡힙니다. 이후 챕터에서 이 CSV 를 가공하는 프롬프트를 쓸 때 컬럼명을 정확하게 부를 수 있게 됩니다.

**팁**: "**컬럼별 값의 범위(최소·최대) 도 함께 보여줘**" 를 추가하면 이상치 파악도 됩니다.

## 예시 3. 파일 5개 이름 앞에 오늘 날짜 붙이기

**상황**: 캠페인 이미지 파일명이 `image1.jpg`, `image2.jpg` ... 처럼 관리가 안 된다. 앞에 오늘 날짜를 붙여서 시간순으로 정리하고 싶다.

**프롬프트**:
```
이 폴더의 jpg 파일 5개 이름 앞에 오늘 날짜(YYYY-MM-DD)_ 를 붙여줘.
예: image1.jpg -> 2026-07-27_image1.jpg

실제 변경 전에 변경 계획을 표로 먼저 보여주고, 내가 확인하면 실행해줘.
```

**예상 결과 (실행 전 미리보기)**:
```
| 변경 전       | 변경 후                  |
|--------------|--------------------------|
| image1.jpg   | 2026-07-27_image1.jpg   |
| image2.jpg   | 2026-07-27_image2.jpg   |
...
```

Copilot 이 이 계획을 보여주고 "실행할까요?" 라고 물어봅니다. **1번 (Yes)** 을 누르면 실제로 파일명이 변경됩니다.

**팁**:
- "**변경 사항을 rename_log.csv 로 저장해줘**" 를 추가하면 나중에 되돌리기 용이합니다.
- 되돌리고 싶으면: "방금 변경한 파일명을 원래대로 되돌려줘" 라고 그 자리에서 다시 요청 가능.

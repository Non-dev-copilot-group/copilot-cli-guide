## 각 챕터에서 배우는 것

### Ch 1. 사용법 (초급)

**목표**: 사내 문서·이력서 폴더에 "말을 걸어보는" 첫 경험.

다루는 예시:
- 이력서 PDF 폴더의 파일 개수·이름 목록 확인
- 특정 조건(날짜·문서 유형)에 맞는 파일만 찾기
- 사내 정책 문서 3줄 요약

→ [Ch 1 시작하기](./ch1-basics.md)

### Ch 2. 활용 (중급)

**목표**: 반복 잡업 자동화. 원본 보존 + undo 가능한 안전 패턴.

다루는 예시:
- 사내 문서 폴더 구조 리네이밍 (undo 스크립트 병행)
- 신입사원 5명 온보딩 체크리스트 자동 생성 (팀별 맞춤)
- 사내 정책 여러 개 → 한 페이지 요약

→ [Ch 2 시작하기](./ch2-application.md)

### Ch 3. 현업 활용 (고급)

**목표**: 개인정보를 다루는 대량 처리 + 정기 리포트 자동화.

다루는 예시:
- 이력서 PDF 50개에서 필드 추출 (신뢰도 컬럼, 검토 태그)
- 채용 전형별 대량 이메일 회신 준비 (합격·불합격 초안)
- 분기별 조직 현황 리포트 자동 생성

→ [Ch 3 시작하기](./ch3-professional.md)

# HR / Ops — Ch 1. 사용법 (초급)

> **난이도**: 초급 ★☆☆ | **소요 시간**: 10분 | **선수 학습**: [메인 README](../README.md) 의 1~8장 완료 (설치 · 로그인)

이 챕터는 Copilot CLI 를 처음 켜고 **HR · Ops 에서 매일 다루는 이력서 · 사내 문서에 "말을 걸어보는" 첫 경험** 을 위한 것입니다.

> **주의**: 실제 이력서 · 개인정보를 사용할 경우 [메인 README 8장 안전 수칙](../README.md#8-반드시-알아야-할-안전-수칙) 을 반드시 먼저 확인하세요. 회사에 별도 생성형 AI 이용 지침이 있으면 그것을 우선 따라야 합니다.

---

## 이 챕터에서 배우는 것

- **이력서 PDF 폴더** 의 개요를 자연어로 파악하기
- **특정 조건** 에 맞는 파일만 찾기 (날짜, 문서 유형)
- **사내 정책 문서** 를 3줄로 요약받기

## 준비물

새 폴더를 만들고, 예시 파일을 넣어두세요. 실제 이력서가 없다면 공개된 샘플 이력서 PDF 를 몇 개 넣으시면 됩니다.

```
~/work/copilot-ch1-hr/
  resumes/
    resume_kim.pdf
    resume_lee.pdf
    resume_park.pdf
  meetings/
    2026-07-01_주간회의.md
    2026-07-08_주간회의.md
    2026-06-24_주간회의.md
  policy_2026.md          (사내 정책 문서, 아무 정책 문서 예시)
```

터미널에서 이 폴더로 이동:

```bash
# Windows
cd $env:USERPROFILE\work\copilot-ch1-hr

# macOS
cd ~/work/copilot-ch1-hr

# 그리고 실행 (안전을 위해 rm 은 막고 시작)
copilot --deny-tool='shell(rm)'
```

> **팁**: HR 은 개인정보를 다루므로 시작할 때 `/sandbox enable` 로 로컬 샌드박스를 켜두는 것을 권장합니다. 사용법은 [메인 README 8장](../README.md#8-반드시-알아야-할-안전-수칙) 참고.

## 예시 1. 이력서 PDF 폴더 개요 파악

**상황**: 이번 채용 공고의 지원자 이력서가 폴더에 쌓였다. 몇 명인지, 파일명이 어떻게 되어 있는지 먼저 훑어보고 싶다.

**프롬프트**:
```
./resumes/ 폴더의 PDF 파일 개수를 알려주고,
각 파일의 이름과 크기를 표로 정리해줘.
```

**예상 결과**:
```
총 PDF 파일: 3개

| 파일명           | 크기      |
|------------------|-----------|
| resume_kim.pdf   | 245 KB    |
| resume_lee.pdf   | 189 KB    |
| resume_park.pdf  | 320 KB    |
```

**팁**: 이력서가 많으면 "**파일명에 이름 · 지원 직무가 명확히 드러나는지 검토해줘**" 로 확장 가능. 파일명이 뒤죽박죽이면 Ch 2 의 리네이밍 시나리오로 넘어가면 됩니다.

---

## 예시 2. 특정 조건에 맞는 파일만 찾기

**상황**: 이번 달(2026년 7월) 회의록만 보고 싶다. 폴더에는 여러 달치 회의록이 섞여 있다.

**프롬프트**:
```
./meetings/ 폴더에서 파일명에 "2026-07" 이 포함된 .md 파일만 목록으로 보여줘.
각 파일의 첫 3줄도 미리보기로 함께 표시.
```

**예상 결과**:
```
2026년 7월 회의록 (2개):

1. 2026-07-01_주간회의.md
   > # 2026-07-01 주간 회의
   > 참석자: 홍길동, 김철수, ...
   > 안건: Q3 목표 리뷰

2. 2026-07-08_주간회의.md
   > # 2026-07-08 주간 회의
   > 참석자: 홍길동, ...
   > 안건: 신입 온보딩 준비
```

**팁**: 파일명 규칙이 없거나 날짜가 파일 내용에만 있는 경우 "**파일 내용에서 '2026년 7월' 이 언급된 문서만**" 으로 프롬프트 변경 가능. Copilot 이 파일 내용도 훑어봅니다.

## 예시 3. 사내 정책 문서 3줄 요약

**상황**: 신입사원 온보딩 자료 준비 중. 사내 정책 문서(policy_2026.md) 를 신입이 이해하기 쉽게 3줄로 요약해서 슬라이드에 넣고 싶다.

**프롬프트**:
```
policy_2026.md 파일을 읽고, 신입사원이 이해하기 쉽게 3줄로 요약해줘.

톤은 담백하되 딱딱하지 않게. 어려운 사내 용어가 나오면 괄호 안에 짧게 설명 추가.
```

**예상 결과** (예시):
```
1. 우리 회사의 근무 시간은 자율 출퇴근제(코어 타임 10시~4시)이며,
   월 총 근무 시간을 지키는 것이 원칙입니다.

2. 모든 직원은 연 15일의 유급 휴가를 사용할 수 있고,
   반차/반반차(2시간 단위) 로 나눠 쓸 수 있습니다.

3. 회사 장비(노트북 등)는 개인 용도 사용을 최소화하고,
   퇴사 시 반드시 반납해야 합니다 (분실 시 감가상각 처리).
```

이 요약을 그대로 온보딩 슬라이드 · Notion 페이지 · 이메일에 붙여넣기 가능.

**팁**:
- "**5줄 버전과 10줄 버전도 각각 만들어줘**" 로 여러 길이를 한 번에 확보.
- "**FAQ 형식으로 재작성해줘**" 로 형식 변환도 가능.

# Marketing — GitHub Copilot CLI 실무 시나리오

> **캠페인 데이터 정리, 콘텐츠 운영, 경쟁사 모니터링, 리포트 자동화** 등 마케팅 실무에서 반복되는 업무를 CLI 로 처리하는 5가지 시나리오.

이 폴더는 [메인 가이드](../README.md) 의 Marketing 편입니다. **설치·인증·안전 수칙은 [메인 문서](../README.md)를 먼저 읽어주세요** (특히 [8번 안전 수칙](../README.md#8-반드시-알아야-할-안전-수칙)).

---

## 각 시나리오 읽는 법

- **상황** — 어떤 문제인가
- **프롬프트** — 그대로 복사해서 붙여넣을 수 있는 한국어 명령
- **결과** — 무엇을 받게 되는가
- **팁** — 반복 사용 / 안전 팁

**전제**: 아래 예시들은 모두 대화형 모드(`copilot`) 안에서 입력합니다. 실행 전에 반드시 **작업 전용 폴더** 로 이동해서 실행하세요.

## 시나리오 A. 광고 캠페인 CSV 5개를 통합해서 UTM 별 성과 요약

**상황**: Google Ads, Meta Ads, Naver GFA 등에서 내려받은 CSV 5개가 폴더에 있고, UTM 소스별 총 클릭·전환·비용을 하나의 요약 표로 보고 싶다.

**폴더 준비**:
```
~/work/2026-q3-ads/
  google_ads_202607.csv
  meta_ads_202607.csv
  naver_gfa_202607.csv
  ...
```

**프롬프트**:
```
이 폴더에 있는 광고 CSV 파일 5개를 모두 읽어서, UTM source 별로
총 impressions, clicks, conversions, cost 를 합계로 요약해줘.

결과를 summary_202607.csv 로 저장하고,
CTR (clicks / impressions), CVR (conversions / clicks), CPA (cost / conversions) 도 계산해서 컬럼으로 추가해줘.
컬럼 헤더는 한국어로.
```

**결과**:
- `summary_202607.csv` 파일이 생성됨
- 화면에는 상위 5개 UTM source 요약이 표로 출력됨
- Copilot 이 실행한 파이썬/셸 스크립트 코드도 함께 보여줌

**팁**: 이 프롬프트를 사내 위키에 "**월간 광고 리포트 자동화**" 로 저장해두면, 다음 달에도 새 CSV 만 폴더에 넣고 같은 프롬프트로 재사용 가능합니다.

## 시나리오 B. 블로그 이미지 30장 일괄 리사이즈 + 파일명 정리

**상황**: 신규 블로그 포스팅에 쓸 이미지 30장이 있는데, 각각 크기가 제각각이고 파일명이 `IMG_1234.jpg` 처럼 관리가 안 됨.

**프롬프트**:
```
이 폴더의 모든 jpg/png 이미지를 아래 규칙으로 정리해줘:

1. 가로 최대 1600px 로 리사이즈 (비율 유지, 세로는 자동)
2. 파일명을 blog-2026-07-01.jpg, blog-2026-07-02.jpg ... 순서로 변경
   (원본 파일명 사전순 정렬 기준)
3. 결과를 ./resized/ 폴더에 저장 (원본은 건드리지 말 것)
4. 변환 전후 파일명과 크기를 표로 요약해서 보여줘
```

**결과**:
- `./resized/` 하위에 정리된 이미지 30장
- 원본은 그대로 보존됨
- 변환 매핑 표가 화면에 출력됨 (이걸 사내 문서에 붙여넣으면 됨)

**팁**: 이미지 처리는 Copilot 이 대부분 Python 의 `Pillow` 나 `sharp` 같은 도구를 자동으로 씁니다. 없으면 설치 승인을 요청하니 안심하고 Yes 누르세요.

## 시나리오 C. 경쟁사 블로그 5개 URL 을 받아서 주간 콘텐츠 트렌드 정리

**상황**: 매주 월요일마다 경쟁사 블로그를 확인해서 어떤 주제를 다루는지 정리해야 함.

**프롬프트**:
```
아래 URL 5개의 블로그를 각각 방문해서 최근 1주일 새 글의
제목/발행일/핵심 주제(3줄 요약) 를 정리해서 competitors_weekly.md 파일로 저장해줘.

URL:
- https://blog.example-a.com
- https://blog.example-b.com
- https://blog.example-c.com
- https://blog.example-d.com
- https://blog.example-e.com

문서 최상단에 "이번 주 3대 트렌드" 도 요약해줘.
```

**결과**:
- `competitors_weekly.md` 파일 생성
- 주간 회의 자료로 바로 사용 가능

**팁**: 매주 같은 프롬프트를 재사용하되, URL 만 최신으로 유지하세요. `~/work/competitor-watch/` 폴더 하나 만들어두고 매주 그 안에서 실행.

## 시나리오 D. Google Analytics 원본 export → 임원 보고용 초안

**상황**: GA4 에서 내려받은 4주치 CSV 를 임원에게 보고할 5장짜리 마크다운 초안으로 변환.

**프롬프트**:
```
ga4_export_20260701_20260728.csv 를 분석해서, 임원 보고용 요약을
아래 구조로 report.md 파일로 만들어줘:

1. Executive Summary (3~5줄, 전주 대비 증감 포함)
2. 상위 5개 랜딩 페이지 (세션 수, 이탈률, 평균 체류)
3. 유입 채널별 성과 (직접/오가닉/유료/소셜/이메일)
4. 이번 달 눈에 띄는 이상치 3가지 (수치 근거 포함)
5. 다음 달 액션 아이템 제안 3가지

숫자는 콤마 구분자, 증감률은 %로 표시. 톤은 담백하고 사실 중심으로.
```

**결과**: 회의 자료로 바로 붙여넣을 수 있는 `report.md`.

**팁**: 마크다운 → Notion / 슬라이드로 그대로 붙여넣기 가능. Copilot 에게 "이걸 PPT 로 만들 수 있는 개요로 다시 정리해줘" 라고 후속 요청도 가능.

## 시나리오 E. 뉴스레터 발송 리스트 클렌징

**상황**: Mailchimp export 리스트에 중복 이메일, 오타 이메일, 회사 도메인 아닌 것들이 섞여 있음.

**프롬프트**:
```
mailchimp_export.csv 를 클렌징해줘:

1. 이메일 중복 제거 (대소문자 무시)
2. 명백한 오타 이메일 (@ 없음, .com 오타 등)은 removed_reason 컬럼에 사유 적고 별도 파일 rejected.csv 로 분리
3. 자유이메일 (gmail, naver, daum 등)과 회사이메일(그 외) 를 구분하는 category 컬럼 추가
4. 정제 결과 요약 (원본 N건 → 유효 M건 → 자유 X / 회사 Y)

원본은 건드리지 말고 cleaned.csv 로 저장.
```

**팁**: **원본은 건드리지 말 것** 을 프롬프트에 명시하는 습관이 안전합니다.

## Marketing 실무자 추천 프롬프트 패턴

1. **"원본은 건드리지 말 것"** 문구를 항상 명시 (실수 방지)
2. **광고 지표 계산 공식**을 프롬프트에 명시 (CTR, CVR, CPA, ROAS 정의는 회사마다 다름)
3. **결과 파일에 날짜/기간 포함** (예: `summary_202607.csv`) — 나중에 시계열 비교 쉬움
4. **한국어 컬럼 헤더 요청** — 그대로 보고서에 붙여넣기 가능
5. **회사 톤앤매너 문서를 폴더에 함께 두기** — Copilot 이 참조 가능 (`brand_voice.md`, `style_guide.md` 등)
6. **원본 → 결과 매핑 로그** 를 함께 요청 — 정제 결과 검증용

# Sales — GitHub Copilot CLI 학습 로드맵

> **리드 리스트 정규화, 견적서 대량 생성, 계약서 검토, TAM 분석, 콜드 아웃리치 개인화** 등 세일즈 실무를 CLI 로 자동화하는 3-챕터 코스.

이 폴더는 [메인 가이드](../README.md) 의 Sales 편입니다. **먼저 [메인 README](../README.md) 의 1~8장(설치 · 인증 · 안전 수칙)을 완료**하고 오세요. 세일즈는 고객 정보를 다루므로 [8번 안전 수칙](../README.md#8-반드시-알아야-할-안전-수칙) 을 특히 꼼꼼히 읽어 주세요.

## 각 챕터에서 배우는 것

### Ch 1. 사용법 (초급)

**목표**: 세일즈에서 매일 마주하는 CSV·PDF·엑셀 파일에 "말을 걸어보는" 첫 경험.

다루는 예시:
- 리드 CSV 총 건수 · 지역 분포 파악
- 견적서 템플릿의 치환 필드 확인
- 계약서 폴더 훑어보기 (파일 수, 총 계약 기간)

→ [Ch 1 시작하기](./ch1-basics.md)

### Ch 2. 활용 (중급)

**목표**: 반복 업무의 자동화. 원본은 보존하며 결과 파일 별도 저장.

다루는 예시:
- CRM Export 리드 리스트 정규화 (회사명·지역 통일)
- 견적서 30건 자동 생성 (엑셀 템플릿 채우기)
- 콜드 아웃리치 이메일 30건 개인화 초안

→ [Ch 2 시작하기](./ch2-application.md)

### Ch 3. 현업 활용 (고급)

**목표**: 여러 자료를 통합·검증하고, 정기 리뷰 회의 자료를 자동 생성.

다루는 예시:
- 계약서 PDF 20건에서 특정 조항 감사 (신뢰도 컬럼 포함)
- 지역별 잠재 TAM 산정 자료 통합 (자료 출처 추적)
- 월간 파이프라인 리뷰 자동화 (전체 워크플로우)

→ [Ch 3 시작하기](./ch3-professional.md)

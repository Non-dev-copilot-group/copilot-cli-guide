# Sales — Ch 1. 사용법 (초급)

> **난이도**: 초급 ★☆☆ | **소요 시간**: 10분 | **선수 학습**: [메인 README](../README.md) 의 1~8장 완료 (설치 · 로그인)

이 챕터는 Copilot CLI 를 처음 켜고 **세일즈에서 매일 다루는 리드 CSV · 견적서 · 계약서에 "말을 걸어보는" 첫 경험** 을 위한 것입니다. 각 예시는 5분 이내에 결과를 확인할 수 있습니다.

> **주의**: 실제 고객 데이터를 사용할 경우 [메인 README 8장 안전 수칙](../README.md#8-반드시-알아야-할-안전-수칙) 을 반드시 먼저 확인하세요. 이 챕터는 예시 데이터로 연습하는 것을 권장합니다.

## 이 챕터에서 배우는 것

- **리드 CSV** 를 훑어보고 총 건수 · 지역 분포를 자연어로 파악하기
- **견적서 템플릿** 의 치환 필드를 자동 파악하기
- **계약서 PDF 폴더** 의 개요를 표로 정리하기

## 준비물

새 폴더를 하나 만들고, 그 안에 세일즈 관련 파일 몇 개를 넣어두세요. 실제 데이터가 없으면 아래 예시 데이터로 시작:

```
~/work/copilot-ch1-sales/
  leads.csv                  (컬럼: name, company, email, region, industry)
  quote_template.xlsx        (치환 필드 {{...}} 가 있는 견적서 템플릿)
  contracts/
    contract_A.pdf
    contract_B.pdf
    contract_C.pdf
```

터미널에서 이 폴더로 이동한 뒤 `copilot` 을 실행:

```bash
# Windows
cd $env:USERPROFILE\work\copilot-ch1-sales

# macOS
cd ~/work/copilot-ch1-sales

# 그리고 실행
copilot
```

## 예시 1. 리드 CSV 총 건수 · 지역 분포 파악

**상황**: CRM 에서 방금 내려받은 leads.csv. 총 몇 건인지, 지역별로 어떻게 퍼져 있는지 먼저 파악하고 싶다.

**프롬프트**:
```
leads.csv 파일의 총 리드 건수와 region 컬럼 값별 분포를 표로 보여줘.
region 이 비어있거나 이상한 값은 "미상" 으로 묶어서 표시.
```

**예상 결과**:
```
총 리드 건수: 1,247건

| 지역   | 건수 | 비율   |
|--------|------|--------|
| 서울   | 512  | 41.1%  |
| 경기   | 298  | 23.9%  |
| 부산   | 143  | 11.5%  |
| 대전   | 87   | 7.0%   |
| ...    | ...  | ...    |
| 미상   | 22   | 1.8%   |
```

**팁**:
- "**industry 컬럼도 같은 방식으로 분포 보여줘**" 라고 이어서 요청 가능.
- 결과가 마음에 들면 "**이 결과를 leads_summary.md 로 저장해줘**" 로 파일 생성.

## 예시 2. 견적서 템플릿 치환 필드 확인

**상황**: 사내 견적서 xlsx 템플릿을 새로 받았다. 어떤 정보를 채워 넣어야 하는지 셀 하나씩 열어보기 전에, Copilot 이 요약해주면 좋겠다.

**프롬프트**:
```
quote_template.xlsx 파일 안에서 {{...}} 형태의 치환 필드를 모두 찾아서
각 필드가 어떤 정보를 채워야 하는지 표로 정리해줘.

찾은 필드가 위치한 시트 이름과 셀 주소도 함께 표시.
```

**예상 결과**:
```
| 치환 필드          | 위치           | 채워야 할 정보 (추정) |
|--------------------|----------------|-----------------------|
| {{CLIENT_NAME}}    | Sheet1 !B3     | 고객사명              |
| {{CONTACT_EMAIL}}  | Sheet1 !B4     | 담당자 이메일         |
| {{AMOUNT}}         | Sheet1 !D12    | 견적 금액             |
| {{VALID_UNTIL}}    | Sheet1 !B25    | 유효 기간 (날짜)      |
```

이 정보만 있어도 다음 챕터에서 **"이 CSV 를 이 템플릿에 넣어서 30건 견적서 생성"** 같은 프롬프트를 정확하게 쓸 수 있습니다.

**팁**: 치환 필드 표기가 `{{...}}` 가 아닐 수도 있습니다. "**혹시 `[...]`, `<...>`, `$...$` 같은 다른 표기의 필드도 함께 찾아줘**" 를 추가하세요.

## 예시 3. 계약서 폴더 훑어보기

**상황**: 지난해 체결된 계약서 PDF 3~20개가 든 폴더가 있다. 계약자·계약 기간을 한눈에 보고 싶다.

**프롬프트**:
```
./contracts/ 폴더의 모든 PDF 파일을 훑어서 아래 정보를 표로 정리해줘:

- 파일명
- 계약 당사자 (양측 회사명)
- 계약 시작일 / 종료일
- 계약 총액 (원문에 있으면)
- 신뢰도 (high/medium/low, low 는 사람이 재확인 필요)

low 신뢰도 파일은 파일명 옆에 [REVIEW] 태그를 붙여줘.
```

**예상 결과**:
```
| 파일명         | 당사자           | 시작일     | 종료일     | 금액       | 신뢰도  |
|----------------|------------------|------------|------------|------------|---------|
| contract_A.pdf | Us / 회사A       | 2025-03-01 | 2026-02-28 | 12,000,000 | high    |
| contract_B.pdf | Us / 회사B       | 2025-06-15 | 2026-06-14 | 8,500,000  | high    |
| contract_C.pdf | Us / 회사C[REVIEW]| 2025-?     | 2026-?     | 미상        | low     |
```

**팁**:
- **"신뢰도" 컬럼은 AI 판단이 개입하는 모든 결과물에 요청** 하세요. 100% 정확한 AI 는 없습니다.
- low 신뢰도 건은 반드시 사람이 재확인해야 합니다.
